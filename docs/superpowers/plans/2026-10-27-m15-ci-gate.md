# AgentSentinel M15 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline, test first, with one read-only final reviewer.

**Goal:** Provide `agentsentinel ci-gate`, an offline PR audit with complete staged diagnostics and no source mutation.

**Architecture:** Three focused verification modules separate source-map reconstruction, static analysis and public report/rendering APIs. Reuse the existing diff parser/healer, path policy classifiers, M8 constant folding/assertion extraction, M9 complexity/handler analysis, and M11 declared API checks. CLI emits JSON and optional GitHub summary artifacts.

**Spec:** User attachment `163e30a6-620b-47cb-88e4-7c237eab2202/Pasted text.txt`.

**Tech Stack:** Python 3.11+, stdlib, existing pytest/Ruff/strict mypy environment, PowerShell.

## Global Constraints

- Eleven-file scope: three CI modules, verification exports, assertion collector, CLI, two new test files, README, STATE and this plan.
- No dependencies, Docker/LLM/network calls, git application, imports or execution of inspected source.
- Workspace is the pre-patch checkout; reconstruction and audit are read-only.
- Preserve all existing assertions/APIs and pre-existing primary-checkout changes.
- UTF-8/LF writes, PowerShell without `&&`, existing virtual environment with `-B`.

## Decisions and Review Focus

- Exit 2 is a precondition/reconstruction failure; policy errors and strict warnings use exit 1. Unsafe paths fail before reading source.
- Validate original hunk counts before healing so coordinate repair cannot hide structural corruption. Preserve no-newline markers and bare CR source content through parser normalization.
- Check both rename endpoints and classify Python if either endpoint is `.py`; a rename cannot hide protected paths or removed interfaces.
- Source maps describe surviving context/unchanged lines; deleted lines have no mapping. Added-line numbers use reconstructed physical LF lines.
- Lexical hygiene inspects the complete touched post-buffer; debugger/reflection/handler introduction uses lexical-scope occurrence identity, preserving unchanged occurrences and exact locations using line_map.
- Reuse M8 folding for conditional/dictionary/return overfit checks. Literal values are not echoed in diagnostics.
- Reuse M9 complexity unchanged; compare both file and function growth against the CI-specific default +10. CC warnings use the directive's exact `Stage 4: Complexity Guard` label.
- Broad handlers with recognized logging are allowed by M15; bare handlers are always errors. Nested function exits/logging do not establish handler safety.
- Public API diagnostics enumerate all incompatible declared symbols using M11's model. Invalid post-Python is an additional SYN-001 error rather than a silent skip.
- Assertion collection receives a contained, deterministic test-file list and prunes VCS/virtual-environment/cache/vendor trees. The shared collector's default behavior remains unchanged.
- Rendering is deterministic for a given report; measured runtime is intentionally variable. Escape untrusted Markdown fields.
- The 500ms SLA is tested on a representative synthetic PR, not asserted for unbounded repositories or arbitrarily large input.
