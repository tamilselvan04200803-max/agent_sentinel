## Global Constraints
- Single operator/dedicated VM; hostile repositories. Multi-tenant service excluded. CI remains static-only, no Docker/LLM/execution dependency.
- Preserve runner signature, read-only rootfs/workspace, network isolation, capability/resource controls, SQLite schema, legacy callers and tests.
- No dependencies, pip, host execution of repository code, Any additions, type ignores, or existing assertion changes.
- PowerShell, no &&; UTF-8/LF writes; use original existing venv with this worktree's src on PYTHONPATH and -B.
- M16 is advisory; coverage opt-in. Unresolved static calls and tracing cannot establish semantic causality or malicious-code safety.
- Keep the prior security review findings open; these feature milestones do not close them.

## Review Focus
- Nested-only edits must not mark enclosing functions changed; lexical duplicates/import aliases/ambiguous calls must not invent graph edges.
- Coverage timeout/setup errors must not become coverage success; cleanup includes detached descendants before shadow removal.
- Clone normalization must preserve operators/global names/attributes and lexical scope, bound work, and avoid warning on unchanged clones.
- JVR must require all criteria on the same task, use macro averaging and retain unresolved outcomes in denominators.
- Gate 3 legacy mismatch codes remain; Gate 5 independently checks a trusted expected digest without claiming SLSA certification.
